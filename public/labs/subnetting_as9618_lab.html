01 · STRUCTURE

How subnetting is structured

Subnetting divides one IP network into smaller logical networks. A subnet mask separates the network part from the host part of a 32-bit IPv4 address.

Network / subnet partShared by the subnetIdentifies the network to which the device belongs.
+
Host partUnique within the subnetIdentifies one device interface in that subnet.
IP address

32-bit logical address

192.168.10.34 is written in dotted decimal as four 8-bit octets.

Subnet mask

32-bit bit mask

Consecutive 1s identify network bits. The remaining 0s identify host bits.

Network ID

IP address AND subnet mask

All devices in one subnet produce the same network ID when the same mask is applied.

Exam definition: subnetting is the process of dividing a network into smaller subnetworks.
02 · BIT MASK & PREFIX

What do the prefix and subnet mask do?

Select a prefix to see its dotted-decimal mask and the number of addresses in the subnet.

CIDR prefix/26
Dotted-decimal mask255.255.255.192
Total addresses64
Usable host addresses62
network bits = 1host bits = 0
Prefix: /26 means that the first 26 bits form the network prefix; the remaining 32 − 26 = 6 bits form the host part.
Subnet mask: in a bitwise AND operation, a mask bit of 1 retains the corresponding IP bit and a mask bit of 0 produces 0. The result is the network ID.

Ordinary IPv4 subnet: usable hosts = 2host bits − 2. The all-zero host part is the network address and the all-one host part is the broadcast address.

03 · SAME NETWORK?

Are two IP addresses on the same network?

AND each IP address with the same subnet mask. Equal network IDs mean that the devices are in the same subnet.

06 · ADVANTAGES & DISADVANTAGES

Evaluate subnetting

State the effect and explain why it is useful or problematic.

Advantages

  • Less network traffic: broadcast traffic is restricted to one subnet, reducing congestion and improving performance.
  • Improved security: traffic between subnets can be controlled by a router or firewall, restricting access to sensitive resources.
  • Easier management: devices can be grouped by department or location, making faults easier to locate.

Disadvantages

  • Fewer host addresses: a /26 has 62 usable host addresses, compared with 254 in a /24.
  • More administration: address ranges, subnet masks, gateways and routing must be planned and configured correctly.
  • Extra routing: communication between subnets requires a router or Layer 3 device, adding cost and a possible point of failure.
Exam technique: write a developed point, for example: “Subnetting reduces broadcast traffic because a broadcast is confined to one subnet; this reduces congestion and can improve network performance.”

One site has split the network into several subnetworks. An IP address in a subnetwork is divided into two parts. Identify and describe the two parts of an IP address in a subnetwork.

Show mark-scheme answer
